# Sklep z personalizowanymi produktami cyfrowymi (WooCommerce)

Wtyczka `content-orders` i motyw `dedykowana` dla WordPress + WooCommerce.

- Generatory: dyplom (PDF), legitymacja, list gończy i karta kolekcjonerska zwierzaka, zwierzak w grze 2D (piksel-art), wierszyk (Claude API, opcjonalnie).
- Kolejka zleceń, automatyczna dostawa mailem, prywatny katalog plików, linki do pobrania przez token.
- Płatność przelewem z kopiowaniem danych i kodem QR (rekomendacja ZBP).
- Zgoda na utratę prawa odstąpienia zapisywana z datą, klasyczna kasa WooCommerce.
- Licznik limitu działalności nierejestrowanej (kwartalny) z alertami e-mail.

Wymagania: PHP 8.1+, GD z FreeType, WooCommerce. Szablony regulaminu i polityki prywatności są szablonami do weryfikacji, nie poradą prawną.
